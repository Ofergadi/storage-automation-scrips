# Infrastructure & Storage Python Automation

A collection of lightweight and efficient Python automation scripts designed to streamline routine system administration tasks, monitor storage capacity, track data retention, and assist with infrastructure migrations in enterprise environments (NetApp, SAN, and Linux/Windows systems).

---

## Features

- **Volume & Capacity Monitoring:** Automated scripts to evaluate available space across aggregates/volumes and map utilization.
- **System Load Tracking:** Real-time checks to identify heavy processes or bottlenecks affecting system performance.
- **Migration Utilities:** Helper scripts to streamline and secure data/volume migration workflows with minimal downtime.
- **Network & Interface Verification:** Automated checks for network interface cards (NICs) and connectivity statuses.
